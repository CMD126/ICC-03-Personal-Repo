# Security Policy

## Scope

This repository contains **educational cybersecurity tools and exercises** developed as part of the ICC-03 program. The tools are intended for learning and authorized testing only.

---

## Reporting a Vulnerability

If you discover a security vulnerability in any script, tool, or configuration in this repository, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, report it privately via LinkedIn:
[https://www.linkedin.com/in/cmdmiguelsousa/](https://www.linkedin.com/in/cmdmiguelsousa/)

Please include:
- A description of the vulnerability and its potential impact
- The affected file(s) and line numbers if applicable
- Steps to reproduce the issue
- Any suggested fix or mitigation

You can expect an acknowledgement within **5 business days** and a resolution or response within **14 business days**.

---

## Responsible Use

All tools in this repository are provided for **educational and authorized testing purposes only**.

- Do not use these tools on systems you do not own or lack explicit written authorization to test
- The ransomware simulator (`ransomware-simulator/`) must only be run inside an isolated VM
- Port scanning and network tools must only target systems you control or have permission to test
- Unauthorized use may be illegal under local, national, or international law
