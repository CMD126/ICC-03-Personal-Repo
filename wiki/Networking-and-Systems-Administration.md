## Notes

### OSI Model
The 7-layer model used to understand how data travels across a network.

| Layer | Name | Examples |
|-------|------|---------|
| 7 | Application | HTTP, DNS, FTP, SMTP |
| 6 | Presentation | SSL/TLS, encryption |
| 5 | Session | NetBIOS, RPC |
| 4 | Transport | TCP, UDP |
| 3 | Network | IP, ICMP, routers |
| 2 | Data Link | Ethernet, MAC, switches |
| 1 | Physical | Cables, hubs, repeaters |

→ [View full cheat sheet](../Networking%20and%20Systems%20Administration/notes/OSI%20Model/README.md)

### Wireshark
Network packet capture and analysis.

| Topic | Details |
|-------|---------|
| Capture filters | `host`, `port`, `net`, `tcp`, `udp` |
| Display filters | `ip.addr`, `tcp.port`, `http`, `dns` |
| Protocol analysis | TCP handshake, HTTP requests, DNS queries |
| TLS inspection | Requires session key log |

→ [View full cheat sheet](../Networking%20and%20Systems%20Administration/notes/Wireshark/README.md)
