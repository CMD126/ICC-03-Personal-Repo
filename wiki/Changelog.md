# Changelog

Full version history of the ICC-03-Personal-Repo.

---

## v3.0.0 — 2026

**Repository restructure.**

- Merged `/Notes` and `/Exercises` into unified topic-based module folders at the root
- Each module now has `notes/` and `exercises/` subdirectories
- Removed `Module X -` prefix from all folder names
- Updated `README.md` and `CONTRIBUTING.md`

---

## v2.3.0 — 2026

**New scripts + cleanup.**

- Added `hash-toolkit` — hash identification, generation, file integrity, comparison
- Added `recon-tool` — OSINT and reconnaissance automation (8 modules)
- Upgraded `network-tool` v3.0 → v4.0 (4 new features, menu reorganized)
- Removed `basic-shell-commands` (not relevant to cybersecurity)
- Removed Module 0 and Module 1 exercises (too basic)

---

## v2.1.0 — 2025

**Script renames.**

All scripts renamed to combine tool name with function description (e.g., `net_diagnostic_tool.sh`, `nmatrix_nmap_scanner.sh`).

---

## v2.0.0 — 2025

**Major reorganization.**

- Module-based folder structure for Notes and Exercises (Module 0–8)
- New exercises: `password-auditor`, `log-analyzer`, `port-scanner`, `web-headers-checker`
- New cheat sheets for all modules
- Added `SECURITY.md`, `CONTRIBUTING.md`, `CHANGELOG.md`, issue templates, PR template

---

## v1.0.0 — 2025-03

**Initial release.**

Basic repo with `/Scripts`, `/Exercises`, `/Notes`. First scripts: `syscript`, `NMATRIX`, `Network-Tool`, `ABDNS`. First notes: Linux, Ubuntu, OSI Model, Wireshark, Nmap.
